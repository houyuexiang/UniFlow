所有接口均以 /api 为前缀（如 http://服务器:5100/api/health）。支持 GET 请求的接口可直接在浏览器打开。
标注 Auth required 的端点需先 GET /api/auth/challenge 取一次性 nonce（60 秒、一次一用），再带请求头 X-Admin-Nonce 与 X-Admin-Hash = SHA-256(管理密码+nonce)（小写 hex）。鉴权成功的响应还会下发 X-Admin-Token（管理验证记忆，默认 WebAdmin:AuthMemoryMinutes=5 分钟）：其后的破坏性动作只带 X-Admin-Token 即可（令牌过期/改密码/进程重启后失效）。管理密码（WebAdmin:AdminPassword）在后台 appsettings.json 修改，页面不提供修改。
